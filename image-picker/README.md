# 콘텐츠 이미지 추천기

큐레이션 콘텐츠(주제·본문)에 어울리는 **실제 호텔 사진**을 Synology NAS에서 빠르게 불러와
추천해 주는 로컬 웹 앱. 무의존성 Node.js(내장 모듈만) — `npm install` 불필요.

> ⛔ **NAS 읽기 전용.** 이 프로그램은 NAS에서 조회·썸네일·다운로드만 하며,
> 파일 생성/삭제/이름변경/이동/업로드 등 어떤 쓰기·수정도 하지 않습니다.

## 준비 (1회)

```bash
cd "contents maker/image-picker"
cp nas.config.example.json nas.config.json
# nas.config.json 을 열어 NAS 아이디/비밀번호를 입력 (2단계 인증 시 otp도)
```

AI 추천을 쓰려면 API 키도 넣습니다(둘 중 하나):
- `nas.config.json` 의 `apiKey` 필드에 입력, 또는
- `cp ai.config.example.json ai.config.json` 후 `apiKey` 입력

> 비밀번호·API 키는 본인이 직접 입력하세요. 이 값들은 로컬 config 파일에만 저장되며 외부로 전송되지 않습니다.
> (AI 추천 사용 시 후보 사진의 썸네일만 Anthropic API로 전송됩니다.)

## 실행 (더블클릭 — 터미널 입력 불필요)

Finder에서 `image-picker` 폴더를 열고 더블클릭하세요.

### ✅ 권장: `실행.command` 더블클릭
바로 동작합니다. 터미널 창이 하나 뜨고 → 서버가 켜지고 → 브라우저가 자동으로 열립니다.
- 종료: 그 창에서 `Control(^) + C` 를 누르거나 **창을 닫으면** 됩니다.
- (`종료.command` 를 더블클릭해도 종료됩니다.)

> `실행.command`가 만약 텍스트로 열리면(연결 앱이 바뀐 경우): 파일 **오른쪽 클릭 → 다음으로 열기 → 터미널(Terminal)**.

### (선택) 터미널 창 없이 — `이미지 추천기.app`
아이콘 방식으로 열고 싶으면 이 앱을 쓰되, **서명이 없어 macOS가 처음엔 차단**합니다. 한 번만 허용하면 됩니다:
1. 앱을 더블클릭 → "열 수 없음" 경고가 뜸 → **취소**.
2. **시스템 설정 → 개인정보 보호 및 보안** 으로 이동 → 아래로 스크롤 → *"이미지 추천기'을(를) 사용할 수 없도록 차단했습니다"* 옆의 **"그래도 열기"** 클릭 → **열기**.
3. 이후로는 더블클릭으로 열립니다.
   (macOS 버전에 따라 오른쪽 클릭 → 열기 → 열기 로 되기도 합니다.)

> `.app`은 폴더 경로를 기억하므로 폴더를 옮기면 `실행.command`를 쓰세요(위치 무관).
> 번거로우면 그냥 **`실행.command`** 만 쓰셔도 충분합니다.

## 실행 (터미널)

```bash
node server.js
# → http://localhost:8787
```

## 사용법

1. **입력** — “호텔 직접 선택”에서 호텔을 고르거나(⌘/Ctrl·Shift로 **여러 호텔 = 큐레이션 콘텐츠**),
   “콘텐츠 md 불러오기”에서 기존 `큐레이션_콘텐츠_*.md`의 주제를 선택(주제·본문·매칭호텔 자동 반영).
2. **이미지 검색** — 호텔 폴더를 자동 해석(호텔명↔폴더명이 달라도 퍼지 매칭)해 썸네일 갤러리를 띄웁니다.
   파일명이 무의미해도 **카테고리 폴더명**(객실/로비/라운지 등)이 타일에 배지로 표시됩니다.
   폴더가 잘못 잡히면 **“혹시 이 폴더?”** 후보나 **“직접 찾기”** 트리로 보정하세요(단일 호텔 모드).
3. **필터 & 추천(무료·API키 불필요)** — 상단 키워드 칩으로 1차 필터 후
   **📁 Claude에게 보낼 폴더로 저장** → 후보 썸네일이 로컬 `exports/`에 저장되고,
   화면에 뜬 문장을 **Claude Code 채팅에 붙여넣으면** Claude가 이미지를 직접 보고 콘텐츠에 맞는 사진을 추천합니다.
   *(선택) `ai.config.json`에 API 키를 넣으면 “✨ API로 자동 추천” 버튼으로 프로그램 자체 추천도 가능(유료).*
4. **선택/다운로드** — 타일 클릭으로 선택, 더블클릭으로 크게 보기,
   **📥 선택 원본 다운로드**로 고른 사진 원본을 브라우저 다운로드 폴더로 내려받습니다.
   “경로 목록 복사”로 NAS 경로를 클립보드에 담을 수도 있습니다.

> 다른 Claude/담당자가 이어서 작업할 때는 **`작업내역_HANDOFF.md`** 를 참고하세요.

## 로딩 최적화

- 갤러리는 원본이 아니라 **Synology Thumb API** 썸네일(small)만 사용.
- 화면에 보이는 썸네일만 요청하는 **지연 로딩**(IntersectionObserver).
- 서버가 썸네일을 `.thumbcache/` 에 **디스크 캐시** → 두 번째 로드는 즉시.
- 원본은 개별 선택 시에만 다운로드.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `server.js` | HTTP 서버·라우팅, 썸네일 캐시/프록시 |
| `synology.js` | FileStation 클라이언트(로그인·목록·검색·저해상 폴더 해석·썸네일·다운로드) — **읽기 전용** |
| `content.js` | 호텔 목록(`prizm_all_*.json`)·콘텐츠 md 파서 |
| `recommend.js` | Claude 비전 추천(내장 fetch로 Anthropic Messages API 호출) |
| `public/` | 갤러리 프론트엔드 |
| `hotel-folder-map.json` | 해석된 호텔→NAS 경로 캐시(자동 생성) |

## 참고

- 호텔 데이터는 상위 폴더의 `prizm_all_YYYYMMDD.json`(콘텐츠 프로젝트 산출물)을 재사용합니다.
- `저해상` 폴더명이 조금씩 달라도 `저해상/저용량/웹용/low` 등을 폭넓게 매칭하고,
  못 찾으면 이미지가 가장 많은 하위 폴더로 폴백합니다. 그래도 틀리면 “직접 찾기”로 지정하세요.
